# Prompt Claude Squad pour le Chat

## Utilisation simple :

```
J'utilise claude-squad, un gestionnaire d'agents IA terminaux multiples qui permet de coordonner Claude Code, Codex, OpenCode et Amp.

Je viens d'intégrer claude-squad dans mon projet Tracer (branche claude-squad). Aide-moi à :
1. Configurer les agents disponibles
2. Mettre en place la communication entre agents
3. Créer des workflows pour coordonner les agents
```

## Variante courte :

```
J'ai claude-squad intégré dans Tracer. Aide-moi à configurer les agents IA multiples et leurs interactions.
```

## Pour déboguer :

```
Claude Squad est actif sur le projet Tracer (branche claude-squad). Diagnostique le statut d'installation et propose les prochaines étapes de configuration.
```
