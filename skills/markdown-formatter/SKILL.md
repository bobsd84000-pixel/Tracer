# Markdown Formatter

Formats markdown tables to align columns and validates list syntax.

## Features

- Aligns markdown table columns
- Validates list formatting
- Converts between list styles (-, *, +)

## Usage

```
Format this markdown table:
| Col1 | Col2 |
|---|---|
| A | B |
| Very Long | C |
```

## Output

Returns formatted markdown with aligned columns and validated syntax.
